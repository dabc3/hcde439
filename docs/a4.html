Calculations:

For the photoresistor, I took measurements of the resistance in both the light (Rlow) and the dark (Rhigh) using my multimeter, and used the equation R2 = sqrt(Rlow x Rhigh). I then rounded to the nearest resistor which would be 10K ohms. This was the same process I used for the thermistor, but instead of light and dark conditions, I measured the resistance when I was touching it and not.

Code Snippet:

          #include < Servo.h>

          Servo myservo;  // create Servo object to control a servo

          int potpin = A0;  // analog pin used to connect the potentiometer
          int therpin = A1;  // analog pin used to connect the thermistor
          int light;    // variable to read the value from the potpin
          int temp;     // variable to read the value from the therpin

          void setup() {
            myservo.attach(9);  // attaches the servo on pin 9 to the Servo object
          }

          void loop() {
            myservo.write(0);                     // start the motor position at 0
            light = analogRead(potpin);           // reads the value of the potentiometer (value between 0 and 1023)
            light = constrain(light, 208, 815);   // constrains the light value's max and min (between 208 and 815)

            temp = analogRead(therpin);            // reads the value of the thermistor (value between 0 and 1023)
            temp = constrain(temp, 463, 517);      // constrains the temp value's max and min (between 463 and 517)

            if(light > 511 && temp >= 490){        // if the light sensor and temp sensor read more than the halfway
                                                   // point, (more light and more warm)
              myservo.write(180);                  // move the motor all the way to 180
              delay(1000);                         // delay loop for one second otherwise the motor will move back to 0
            }
          }
