Calculations:

Using the equation I = V*R, I rearranged the equation to solve for R which is the resistor. I found V using the total voltage (5V) minus the volatage drop over the LEDs (2V for red LEDs and 3.2V for the green LED). I calculated for 20mA over each circuit and solved for each circuit individually, because I constructed parallel circuits.

Graph:

Because the lights are turning on and off, they are going from complete voltage output to zero voltage output. The voltage drop is 2V for red LEDs and 3.2V for the green, which is why LED 1 and three max out at 2V for their peak output and why LED2 goes up to 3.2V. The red and green lights are also flashing opposite, which explains why LED1 and LED3 are 0 when LED2 is peaked and vise versa.



Code Snippet:

          // assign LEDs to their designated pins for later reference
          int LED1 = 11;
          int LED2 = 10;
          int LED3 = 9;

          // the setup function runs once when you press reset or power the board
          void setup() {
            // initialize digital pin LED1 as an output.
            pinMode(LED1, OUTPUT);
            // initialize digital pin LED2 as an output.
            pinMode(LED2, OUTPUT);
            // initialize digital pin LED3 as an output.
            pinMode(LED3, OUTPUT);
          }

          // the loop function runs over and over again forever
          void loop() {
            // turn LED1 on (HIGH is the voltage level)
            digitalWrite(LED1, HIGH);
            // turn LED3 on (HIGH is the voltage level)
            digitalWrite(LED3, HIGH);
            // turn the LED2 off by making the voltage LOW
            digitalWrite(LED2, LOW);
            // wait for a second
            delay(1000);

            // turn the LED1 off by making the voltage LOW               
            digitalWrite(LED1, LOW);
            // turn the LED3 off by making the voltage LOW
            digitalWrite(LED3, LOW);
            // turn LED2 on (HIGH is the voltage level)
            digitalWrite(LED2, HIGH);
            // wait for a second
            delay(1000);        
          }
