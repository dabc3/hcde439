Calculations:

Using the equation I = V*R, I rearranged the equation to solve for R which is the resistor. I found V using the total voltage (5V) minus the volatage drop over the LEDs (2V for red LEDs and 3.2V for the green LED). I calculated for 20mA over each circuit and solved for each circuit individually, because I constructed parallel circuits.

Graph:

Because the lights are turning on and off, they are going from complete voltage output to zero voltage output. The voltage drop is 2V for red LEDs and 3.2V for the green, which is why LED 1 and three max out at 2V for their peak output and why LED2 goes up to 3.2V. The red and green lights are also flashing opposite, which explains why LED1 and LED3 are 0 when LED2 is peaked and vise versa.



Code Snippet:

          const int buttonPin = 2;  // the number of the pushbutton pin
          int led1 = 9; // the pin LED 1 is attached to
          int led2 = 10; // the pin LED 2 is attached to
          int led3 = 11; // the pin LED 3 is attached to
          int fadeAmount = 5; // how many points to fade the LEDs by
          int brightness = 0; // how bright the led is
          bool fading = false; // boolean to figure out if the lights are on

          // variables will change:
          int buttonState = 0;  // variable for reading the pushbutton status
          int lastButtonState = buttonState; // variable for reading the last pushbutton status

          void setup() {
            // initialize the pushbutton pin as an input:
            pinMode(buttonPin, INPUT);
              // declare pin 9 to be an output:
            pinMode(led1, OUTPUT);
            // declare pin 10 to be an output:
            pinMode(led2, OUTPUT);
            // declare pin 11 to be an output:
            pinMode(led3, OUTPUT);
          }

          void loop() {
            // read the state of the pushbutton value:
            buttonState = digitalRead(buttonPin);
            // if the the button is being pushed (state of button is changing from
            // the last button state)...
            if (buttonState == LOW && lastButtonState == HIGH) {
              // set the fading boolean to the opposite of what it was originally
              fading = !fading;
              // if the boolean is not true (lights are not fading)
              if (!fading) {
                // turn LED 1 off
                analogWrite(led1, 0);
                // turn LED 2 off
                analogWrite(led2, 0);
                // turn LED 3 off
                analogWrite(led3, 0);
              }
              // delay the loop by 30 milliseconds
              delay(30);
            }
            // update the last button state to current button state
            lastButtonState = buttonState;

            // if the boolean is true (lights are currently fading)
            if (fading) {
              // set led 1 to the brightness value
              analogWrite(led1, brightness);
              // set led 2 to the brightness value
              analogWrite(led2, brightness);
              // set led 3 to the brightness value
              analogWrite(led3, brightness);
              // add the fade amount to brightness to make the light brighter
              brightness += fadeAmount;
              // if the brightness is at the lowest or highest point of the oscilltion
              if (brightness <= 0 || brightness >= 255) {
                // reverse direction of bightness fading (aka make the fade amount
                // negative from what it is to fade the other way)
                fadeAmount = -fadeAmount; 
              }
              // delay the speed of fading so we can see a gradual fade
              delay(30);
            }
          }
